# 来源、许可与发布清单

本表记录本仓库这次公开范围以及复现限制。公开源码没有统一授予许可证：文件旁标明的第三方许可只适用于相应文件；未标许可的项目代码没有因此自动变成开源代码。发布其他文件前应先核实来源、授权、隐私和文件内容。

## 已纳入内容

- `docs/` 中的格式笔记、工作流程与复现说明。主要记录 CHD/ISO/CVM/NBL/AFS、PRS、UTF-16LE 文本和字库的工程分析，不携带游戏容器、完整提取文本或贴图音频。部分历史参数及经验的证据边界见各文件说明。
- `scripts/` 中独立实现的 Python 工具源码和不访问游戏数据的 `smoke_check.py`。这些脚本按文件逐项选择，并非完整构建套件。
- `scripts/prs.py` 参照 MIT 许可的 `rust-ages-prs` 项目；对应 MIT 文本保存在 `LICENSES/MIT-rust-ages-prs.txt`。本地实现使用 PSU/Legacy 变体长度语义，扩展长度字节加 1；脚本旧头注的“Modern/+10”有误。
- `scripts/swizzle_ps2_4bit.py` 源文件标记为 Bartłomiej Duda 版权所有并使用 GPL-3.0；因当前快照尚未一并附上完整许可文本，该文件暂缓发布。

## 暂不纳入的源码

以下文件仍在本地原位保留。没有推断未知授权，也没有以重写、LFS 或其他形式绕过许可边界。

| 路径/范围 | 原因 |
|---|---|
| `scripts/rofs_crypt.py` | 文件声明是 `tools/cvm_tool_src/rofs_crypt.cpp` 的 Python 移植；上游 README 对 roxfan 的贡献写明没有另行许可证。 |
| `tools/cvm_tool_src/` | 混合 roxfan 未授权部分与 JayFoxRox 的 CC0 贡献，不能把整个目录按 CC0 复制发布。 |
| `scripts/nbl.py`、`scripts/blewfish.py`、`scripts/bf_tables.py` | 文件声明参考或提取自 `tools/psu_ae_src/PSULib`；其源码仓库没有覆盖这些代码的清晰总许可声明。 |
| `tools/psu_ae_src/` | 第三方程序与 PSULib 源码，仓库中未找到能确认 NBL/BlewFish 代码再分发权限的许可文件。 |
| `scripts/check_log.py` | 本地会话日志处理脚本绑定到个人日志，且其用途/数据不适合作为项目运行工具发布。 |
| `scripts/swizzle_ps2_4bit.py` 及调用它的 `patch_title_menu.py` | 文件声明 GPL-3.0，待随附完整许可文本后再审查。 |
| `scripts/decrypt_par3.py` | 含查表数据，当前未能核实该表与相关代码的原始来源和再分发许可。 |
| `scripts/patch_text_quick.py`、`scripts/make_unit_titles_cn.py` | 源码内嵌逐条游戏日文到中文的映射；本次没有单独确认这些译文数据的发布范围。 |

上述模块的调用者也从本次仓库快照排除，包括 CVM/NBL 容器回写、批量翻译导入导出、完整构建入口和使用 swizzle 的菜单补丁。这样避免公开无法导入的半套流水线。待源项目许可、作者授权或完整许可证文本确认后，可单独重新审查。

## 暂不纳入的工程数据和二进制

- 游戏原始 CHD、ISO、CVM、ELF、NBL、AFS 文件、转储与资源重建输出。
- 提取对白/文本、全部翻译 TXT/JSON/JSONL、存档、模拟器运行状态，以及最终镜像或其他打包产物。
- 原始/第三方字体文件、外部工具包、模拟器、压缩工具和构建工具的可执行文件及资源。
- `说明.txt` 与标题含“汉化版”的个人发布稿：包含发布平台信息、分发说明或游戏分发链接，不属于可复现技术文档。
- `docs/项目日志.md`：含早期假设、未修订的结果及与当前实现冲突的历史描述；本次不直接发布整个会话档案。可验证的技术结论已移至本次索引指向的主题文档。
- `docs/名词规范.md`：完整游戏专名翻译表的分享范围和来源尚未单独核实。

`.gitignore` 中列出的目录与媒体/游戏文件扩展名会阻止常见本地输入被误加入版本控制；发布仍使用显式文件清单。忽略规则不能替代历史审计。

## 依赖概览

纯 Python 标准库工具不需额外依赖；可选依赖按脚本分组：Pillow 用于 `font_tool.py`；pycdlib 用于 ISO 清单/提取工具；capstone 用于 MIPS 反汇编；pyelftools 用于部分 ELF 交叉引用脚本。numpy、requests 只被本地未发布的脚本使用，不是运行本仓库内容的依赖。具体实测版本见[复现与验证](复现与验证.md)。
