# 汉化路线

> **当前发布快照说明（2026-10-28）**：本仓库提供格式研究文档和一组独立 Python 源码，不包含游戏镜像、完整译文、构建资源或第三方许可未核实的依赖源码。完整端到端的 CVM/NBL 工具链暂时不能仅凭本仓库运行。实际输入准备、脚本依赖与验证界限见[复现与验证](复现与验证.md)及[来源与发布清单](来源与发布清单.md)。下文的早期阶段记录和旧计划按当时状态保留，不应视为当前待办或已完成验收。

## 汉化范围（用户决策 2026-10-24）

**只汉化单机（离线）内容，网络部分一律不动：**
- 跳过：/NETCNF 全部模块、DNAS、网络模式（在线大厅/联机对战/匹配）相关 UI 与文本
- 汉化：故事模式（单机剧情）、Extra 模式、菜单/道具/系统文本、单机可用的台词
- 好处：避开死服内容、减少文本量、规避在线功能测试

## 总体判断

- ~~游戏文本不在主 ELF~~ → 已确认：文本在 PSUROFS.CVM 内的 GA_TEXT_*.NBL / GA_APC_WORDS_*.NBL（**UTF-16LE 编码，游戏按 Unicode 渲染**）。
- **重大利好**：UTF-16 文本 + Unicode 字库意味着汉化不需要换码表/双字节 hack——扩字库贴图 + 写中文 UTF-16 即可。CJK 汉字与日文汉字大量重码，常用 3500 汉字字库即可覆盖绝大多数文本。
- 待确认：主线剧情对话的位置（当前提取到的是战斗/系统/道具层 10,240 串）。

## 风险与未知

| 风险 | 影响 | 缓解 |
|---|---|---|
| 字库位图容量/内存 | 可用字形数受限 | 生成实际用字子集；必要时分语言场景换页 |
| 文本长度超原串 | 偏移表重排 | UTF-16 中文通常比日文短，风险低 |
| NBL 指针区语义 | 回写后游戏崩溃 | 逐文件对比 PSULib 行为；先做小改动闭环验证 |
| 主线剧情文本未定位 | 汉化覆盖不全 | 阶段 3 排查 SU_/SS_/QE_TABLE |
| 双层/单层与 LBA 布局 | 回写后引导失败 | 优先原地替换；大文件重排需回归测试 |
| 在线功能（DNAS 已停服） | 无影响 | 不动 NETCNF 模块 |
