# 字体清单

`fonts/` 下的可用中文字体资源。PS2 游戏汉化通常需要将字体渲染为贴图字库（12~16px 点阵为主），像素字体是首选。

## 概览

| 目录/文件 | 字体 | 格式 | 说明 |
|---|---|---|---|
| `zpix.ttf` | Zpix（最像素） | TTF, 12px, 4.5MB | 中文像素字体标杆，覆盖 GBK 常用字，游戏汉化常用 |
| `unifont.otf` | GNU Unifont | OTF, 16px, 5.3MB | 点阵风格，覆盖极广（含生僻字/符号），保底选择 |
| `fusion10/fusion-pixel-10px-monospaced-zh_hans.ttf` | Fusion Pixel 10px | TTF | 纵向拼接的 10px 等宽简体中文 |
| `fusion12/fusion-pixel-12px-monospaced-zh_hans.ttf` | Fusion Pixel 12px | TTF | 12px 等宽简体中文 |
| `ark-12px/ark-pixel-12px-monospaced-zh_hans.ttf` | Ark Pixel 12px | TTF | 方舟像素简体中文（另有 ja/ko/繁体子集，可拼合） |
| `xiaodianzhen/xiaodianzhen-8px.ttf` | 小点阵 8px | TTF | 超小点阵，适合空间极紧的 UI |
| `MuzaiPixel/MZPXorig.ttf` | MuzaiPixel | TTF | 无罪像素（日系风格） |
| `MuzaiPixel/MZPXflat.ttf` | MuzaiPixel flat | TTF | 平坦版 |

## 字体使用注意

1. PS2 原生文本渲染多为贴图字库（游戏中字库是图片），字体文件是**生成贴图的原料**，不直接放进 ISO。
2. 生成字库贴图时按游戏原字库的网格尺寸（待逆向确认，预计 12~24px）选择对应像素字体，保证点阵对齐、无抗锯齿模糊。
3. 若原字库带阴影/描边分色版式，需要按同样的版式重绘。
