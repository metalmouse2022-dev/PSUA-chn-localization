# 翻译工作流（给翻译 AI / 协作者）

> **历史状态说明（2026-10-28）**：下文的数字和“已全部翻译完毕”等描述是 2026-10-24 至 2026-10-25 的项目快照。本仓库不发布 `work/translation/`、补翻包或批量译文存档，不能据此取得完整翻译资料。`build_patched.py` 只打包已有替换文件，不会自动执行本页的回填步骤。翻译校验器不与原始导出基线比对，需另行检查条目顺序和原文完整性。自备输入和验证边界见[复现与验证](复现与验证.md)。

> 翻译完成后由工程侧一键回填打包，译者只需处理 txt 文件。

## 目录

- `work/translation/` —— 待翻译 txt（~760 个文件）
  - `词条库_*.txt`：全局唯一句（12,179 句，按频次）——**最优先**
  - `系统与菜单_*` `道具与装备_*` `敌人与战斗_*` `任务文本_*` `剧情文本_*` `剧情事件_*` `角色台词_*` `其他文本_*`
  - `manifest.json`：文件清单（勿动）
- `docs/翻译格式说明.md` —— 格式规则（给翻译 AI 的第一份文档）
- `docs/名词规范.md` —— 译名表

## 条目格式

```
# 00042 [窗口/菜单] @GA_TEXT_J.NBL/WindowText_J.bin:12
> キャンセル
= 取消（官方繁中参考行，如有；禁止修改）
< 取消          ← 只改这一行
```

## 流程

1. 翻译 AI 按 `docs/翻译格式说明.md` 填写 `< ` 行
2. 校验：`python scripts/trans_validate.py work/translation`（必须 0 错误）
3. 回填：`python scripts/trans_import.py`（生成 work/cvm_replace/）
4. 打包：`python scripts/build_patched.py "outputs/PSUA(cn).chd"`
5. PCSX2 实测 → 发现问题回到 1

## 硬约束（校验脚本强制）

- `%s`/`%d` 等格式符数量顺序不可变
- 用字限制在 GB2312 一级 + 原字库（生僻字显示方块）
- 条目不可增删调序；`#` `>` `=` 行不可改
- 转义：`\n`=换行 `\\`=反斜杠

## 构建配方（v6 定型，2026-10-25 实机验证）

```bash
# 1. 回填（词条库+逐句+占位符保护+外语条目保护+指针目标钉住）
python scripts/trans_import.py work/translation work/cvm_extracted work/cvm_replace work/all_text.json
# 2. 验证（外语0违规 / 钉住布局等价 / 内嵌指针0异常 / 假名降幅统计）
python scripts/validate_v5.py
# 3. 打包（字库→CVM→ISO→CHD）
python scripts/build_patched.py "outputs/PSUA(cn-vN).chd"
```

新译文进来只需放进 work/translation/（词条库/GLOSSARY 格式或逐句格式均可）重跑 1→3。
校验工具：trans_check_chars.py（字库预检）、check_trans_glyphs.py（成品字形终检）。
