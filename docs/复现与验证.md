# 复现与验证

本文描述公开源码的边界，以及具备合法本地游戏输入时如何复核汉化工程。游戏镜像、原始/修改后的游戏二进制、完整翻译文件、贴图音频、字体和存档不属于本仓库。

## 环境

工程在 Windows x64、Python 3.12.10 环境中整理。实际观察到的 Python 包版本：Pillow 13.0.0、numpy 2.5.3、pycdlib 1.22.0、requests 2.34.2、capstone 5.0.9、pyelftools 0.33。源码使用标准库以外的依赖时，按所用脚本安装：字体/图片工具需要 Pillow；菜单贴图和 4-bit 图像工具需要 Pillow 与 NumPy；ISO 清单/提取工具需要 pycdlib；可选在线翻译工具需要 requests；反汇编与 ELF 交叉引用工具需要 capstone，相关 ELF 工具另需 pyelftools。

安装单项依赖示例：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install Pillow numpy pycdlib requests capstone pyelftools
```

这条命令覆盖本地完整工程的可选依赖；因来源审查而未纳入本仓库的脚本会用到 numpy 和 requests。仅运行这里发布的脚本时，可裁剪未使用的包。上述版本是工程整理时的实测环境记录，不表示已验证其他版本。

## 不带资源的检查

```powershell
python -B scripts/smoke_check.py
```

该脚本不读取游戏文件、不联网、不写入工程资源。它对 Python 源码做语法编译，并使用小型内存数据检查 PRS 压缩/解压、AFS/MiniAFS 重建，以及 UTF-16LE 分组文本解析/回写。通过结果不等于真实游戏输入检查、补丁构建或游戏运行验收。

## 本地输入与工作流

完整流水线要求用户自行从合法来源准备匹配版本的 PS2 日版游戏镜像（编号 `SLPM_666.63`，对应日志记录中的 Data SHA1 为 `a0f572a27b0984f813d1f740f8453c0e8d564066`）。把原始文件放在工程私有工作目录 `work/original/`；根据当前工具参数，本地解包/提取结果放在 `work/` 的相应子目录。工程原先使用 `work/cvm_extracted/` 保存提取容器，`work/cvm_replace/` 保存准备回填的替换文件，`work/translation/` 保存本地翻译 TXT。所有这些目录均由 Git 忽略。

示意流程：

1. 使用本地匹配输入，按 [镜像结构笔记](技术笔记-镜像结构.md) 的历史格式分析记录，从 CHD 取得 ISO，并定位 CVM、NBL/AFS 与文本容器。
2. 准备本地文本导出数据与翻译文件，按 [翻译格式说明](翻译格式说明.md) 编辑，并使用 `scripts/trans_validate.py` 做翻译格式校验。
3. 按 `scripts/trans_import.py --help` 核对本地脚本接口，生成待替换容器。现有公开快照缺少若干依赖许可证未确认的模块，因而部分命令无法仅用本仓库运行；见 [来源与发布清单](来源与发布清单.md)。
4. `scripts/build_patched.py [输出文件名]` 读取本地已有的字库输出、CVM 提取数据、替换目录和打包工具，按字库、CVM、ISO、CHD 的顺序生成输出。它不会自动运行 `trans_import.py`，不会翻译文本，不会执行所有专项 UI/掉落/游戏参数补丁。
5. 使用本地 PCSX2 与自备 BIOS 载入构建结果，逐项核对启动、菜单、道具/任务文本、字形、字体布局与存档兼容性。模拟器验收与 PS2 实机验收应分别记录。

以上步骤是复现路线说明，不代表当前公开仓库已经具备全量输入或完整依赖，也不宣称本次发布执行过镜像构建或 PCSX2/实机验收。

## 当前代码行为的核对要点

`scripts/patch_game_cheat.py` 会修改经验值、武器强化和正向金钱结算相关指令，恢复原生 30 FPS 设置，并调用独立掉落表与玩家成长脚本。它不实现伤害倍率、合成免材料或 60 FPS。旧地址 `0x004455B4` / `0x0044561C` 位于实体通知函数的延迟槽，`$v0` 是实体指针；移位会破坏指针，使怪物不受伤。此实验已撤销，详见 `work/elf/README_DAMAGE_REVERSE.txt`（只在本地，不随仓库发布）。

`scripts/trans_validate.py` 检查译文条目中的格式符和字符范围，但不与原始导出基线比对，不能单独保证编号、原文、参考译文、文件顺序均未被改动。全库实际结果应与对应导出数据、源容器和回填产物一起验证。

## 可选在线翻译

本地完整工程中的 `scripts/translate_all_items.py` 可选请求 `translate.googleapis.com`。使用该流程会将输入文字发送给在线服务；它不是执行离线格式验证的必要条件。该脚本因核心依赖许可尚未确认，未随此仓库发布。本任务未运行该脚本，也未发送原文。

## 本地环境依赖

本地完整工程中的 `scripts/patch_title_menu.py` 指定 Windows 字体文件 `C:/Windows/Fonts/msyhbd.ttc`，但该脚本与其 GPL 授权待核的图像模块未随本仓库发布。字体是本机系统依赖；不得把字体文件随源码提交。若自行修改字体路径，请确认所选字体的使用许可。
