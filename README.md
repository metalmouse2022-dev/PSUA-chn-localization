# PSUA 汉化工程技术资料

本仓库整理 PS2 日版《梦幻之星宇宙：伊尔米纳斯的野心》（*Phantasy Star Universe: Ambition of the Illuminus*，游戏编号 `SLPM_666.63`）汉化工程的格式分析、工作流程和可确认来源的独立工具源码。文档说明如何在本地复现，不包含可启动游戏所需的游戏文件。

## 发布范围

仓库只包含技术文档和逐项审查过的 Python 源码。游戏镜像、程序与容器转储、音视频和贴图、完整或部分译文、成品补丁/镜像、模拟器包与存档、字体文件及个人发布稿均留在本地。术语表和会话日志也暂不发布，分别需要进一步确认分享范围和校正历史记录。依赖来源授权尚不清楚的代码会在 [来源、许可与排除清单](docs/来源与发布清单.md) 中标明。

## 从这里开始

1. 阅读 [复现与验证指南](docs/复现与验证.md)，了解环境、自备输入和验证边界。
2. 阅读 [汉化路线](docs/汉化路线.md)，了解工作阶段和当前范围。
3. 阅读 [翻译格式说明](docs/翻译格式说明.md) 和 [翻译工作流](docs/翻译工作流.md)，了解翻译文件结构与校验工具。
4. 查阅 [镜像结构笔记](docs/技术笔记-镜像结构.md) 及 [数据格式链路笔记](docs/技术笔记-数据格式链路.md)，了解 CHD、ISO、CVM、NBL、AFS、PRS、游戏文本和字库。
5. 浏览 [字体清单](docs/字体清单.md)（仅记录本地盘点与许可证来源，不分发字体）。

## 当前复现状态

- 不带游戏资源的检查命令：`python -B scripts/smoke_check.py`。所有样例在内存中生成；通过仅表示语法与少量自造数据的 PRS、AFS/MiniAFS、UTF-16 文本结构检查通过。
- 生成最终游戏文件还需要用户合法取得并自行准备匹配版本的日版游戏输入、字体和各阶段翻译资料。文件名、版本与放置路径见 [复现指南](docs/复现与验证.md)。仓库没有提供这些输入或最终制品。
- `scripts/build_patched.py` 只打包已存在的替换目录，**不会**替用户导出、翻译或自动回填文本，也不会自动执行各专项贴图和游戏参数补丁。完整模块链的部分源码因第三方许可待核而暂不发布，当前公开快照不能单独完成端到端构建。
- 文档中早期会话的成功/失败记录是历史快照，不能代替当前验收；旧“伤害翻倍”地址实际损坏了实体指针，已撤回。当前游戏补丁脚本的静态行为见复现指南。

## 工具和依赖

独立 Python 工具位于 `scripts/`，用法及依赖按脚本列在 [复现与验证指南](docs/复现与验证.md)。本地完整工程中的 `translate_all_items.py` 可选调用 Google 翻译服务并发送待翻译原文；该脚本及其当前依赖的未授权核心模块不在本仓库中。本仓库不提供任何 API 密钥、游戏输入或字体文件。

## 目录

| 路径 | 用途 |
|---|---|
| `docs/` | 中文格式分析、工作流、现状及来源说明 |
